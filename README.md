# PDF Shoot

Android-застосунок: сканує документи камерою й зберігає їх як PDF.

- **Камера** — власна (CameraX, `CameraScreen.kt`): знімок у найвищій роздільності камери в режимі
  найкращої якості; спалах «Вимк. / Авто / Увімк. / Ліхтар» (вибір запам'ятовується); прев'ю без
  обрізання — у скан іде весь видимий кадр; рамка знайденого документа наживо; дотик — фокус, щипок — зум.
  Перед знімком камера наводить фокус на центр кадру (до 1.5 с), якщо користувач щойно не обрав точку сам:
  без цього зблизька безперервний автофокус часто «плаває» й текст виходить розмитим.
  Фото можна взяти й із галереї.
- **Обробка** — OpenCV на телефоні (`DocImage.kt`), на повній роздільності знімка:
  - пошук країв (кілька порогів Canny і поріг Оцу, кандидати перевіряються тим, чи лежать їхні сторони
    на справжніх краях), трохи всередину від краю — щоб у скан не потрапив стіл. Сторони кандидата
    уточнюються прямими, підігнаними до самих країв (найглибший край у смузі — не край пачки паперів чи
    файлу поруч): трохи вигнутий аркуш інакше не проходив перевірку й у скан ішов увесь кадр;
  - вирівнювання перспективи з відновленням справжніх пропорцій аркуша (Zhang & He; близьке до A4 стає A4);
  - фільтри: «Авто» (рівне освітлення без тіней, білий папір, колір, різкість), «Ч/Б» (сірий із сильним
    контрастом), «Оригінал». Освітлення паперу оцінюється так, щоб великі фото й заливки не вибілювались,
    а глибокі тіні від руки чи телефона — прибирались: темні ділянки розрізаються по різких краях, і та,
    що має здебільшого розмиту межу, — тінь, а з різкою — фото чи заливка;
  - JPEG якості 93 з повним кольором (4:4:4) — червоні печатки й кольоровий текст лишаються чіткими.
- **Сторінки перед збереженням** (`ReviewScreen.kt`) — гортання, фільтр, поворот, видалення, ще сторінка;
  «Межі» — кути й сторони перетягуються, під пальцем лупа з перехрестям.
- **PDF** пишемо самі (`PdfWriter.kt`): готові JPEG кладуться у файл без перетискання.
- **Перегляд** (`ViewerScreen.kt`) — стрічка сторінок. Щипок двома пальцями збільшує й зменшує;
  подвійний дотик — збільшити в точці дотику або назад; подвійний дотик з утриманням і рухом вниз/вгору —
  масштаб одним пальцем. Жести обробляються раніше за прокрутку списку, тож вона їх не перехоплює.
  Збільшене чітке: після жесту видима частина рендериться з PDF у точному масштабі.
- **Поворот сторінок збереженого PDF** (`PagesScreen.kt`) — усі сторінки сіткою, кожну вліво/вправо або
  всі разом; зміни записуються у файл кнопкою «Зберегти». Знімки не перетискаються: міняється лише кут
  `/Rotate` кожної сторінки, запис іде в копію, яка потім замінює файл.
- **Поширення** — системне вікно «Поширити»: месенджери, пошта, диск.

Скани лежать у внутрішній пам'яті застосунку (`files/scans`); після видалення застосунку зникають.
APK ~20 МБ: майже все — OpenCV для arm64-v8a і armeabi-v7a.

## Збірка

```bash
./gradlew :app:assembleDebug          # для розробки, ставиться поряд із релізом (…pdfshoot.debug)
./gradlew :app:testDebugUnitTest      # тест запису PDF
# Обробка на справжньому Android (емулятор чи телефон): синтетичне фото документа в перспективі, з тінню.
# Результати — у /sdcard/Android/data/uk.mwms1488.pdfshoot.debug/files/test, їх варто переглянути очима.
./gradlew :app:connectedDebugAndroidTest   # ще й жести перегляду (щипок, подвійний дотик) і поворот сторінок
./gradlew :app:assembleRelease        # app/build/outputs/apk/release/app-release.apk
```

Реліз підписується ключем `release.keystore` (корінь проєкту), пароль — `release.storePassword` у
`local.properties`. Обидва не в git. **Збережіть їх копію**: без цього ключа нову версію не поставити
поверх старої.

## Випуск

Підняти `versionCode` і `versionName` в `app/build.gradle.kts`, зібрати реліз і викласти:

```bash
./gradlew :app:assembleRelease && tools/release-oracle.sh "Що нового в цій версії"
```

APK лежить на Oracle Cloud VM (`ssh wms-oracle`) у `/opt/inertia-dist/pdfshoot/` — це підтека сайту
Inertia, який роздає Caddy:

- `pdfshoot-<версія>.apk` — кожен випуск; `pdfshoot.apk` — копія останнього, стале посилання:
  <https://92-5-101-235.sslip.io/pdfshoot/pdfshoot.apk> (ним ділиться меню ⋮ → «Поділитися посиланням»).
- `version.json` — номер останньої версії й адреса її APK; скрипт пише його останнім.

## Оновлення

Як в Inertia (`Updater.kt`): застосунок читає `version.json` при кожному поверненні в нього (не частіше
ніж раз на 10 хвилин) і раз на 3 години у фоні (`UpdateJob`). Якщо там вищий `versionCode` — качає APK
і ставить через `PackageInstaller`.

- Android 12+: без запитань, щойно користувач один раз дозволив PDF Shoot встановлювати застосунки
  (Android питає про це при першому оновленні). Старші Android щоразу питають «Оновити?».
- Встановлення закриває застосунок, тому з екрана воно починається лише на списку сканів — не під
  час сканування, введення назви чи перегляду PDF. Відкривати його після оновлення треба вручну:
  Android 10+ не дає застосунку відкрити самого себе.
- Debug-збірка (`…pdfshoot.debug`) себе не оновлює.
- Версії 1.0 і 1.1 оновлюватись не вміють: на них 1.2 ставиться вручну за посиланням.
